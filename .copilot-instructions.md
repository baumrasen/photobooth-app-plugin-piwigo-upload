# Copilot Agent Instructions for photobooth-app Plugin

## Ziel
Erstelle oder erweitere das Photobooth-Plugin `photobooth-app-plugin-piwigo-upload`, damit es erzeugte Medien abhängig vom Medientyp automatisch nach Piwigo hochlädt.

## Anforderungen
- Das Plugin soll ein gültiger `photobooth-app`-Plugin sein.
- Die wichtigsten Einstellungen müssen über die UI konfigurierbar sein.
- Der Upload soll nur für konfigurierte Medientypen erfolgen.
- Das Plugin muss die Piwigo-API nutzen und nach erfolgreichem Upload eine `share_url` setzen.

## Konfiguration
Nutze `PiwigoConfig` als `BaseConfig`.

Erforderliche Felder:
- `enabled`: bool, Plugin aktivieren/deaktivieren
- `api_url`: str, Basis-URL der Piwigo-Instanz
- `username`: str, Piwigo-Benutzername
- `password`: str, Piwigo-Passwort
- `album_id`: int, Zielalbum / Kategorie-ID
- `upload_image`: bool, Upload für Fotos
- `upload_collage`: bool, Upload für Collagen
- `upload_animation`: bool, Upload für Animationen
- `upload_video`: bool, Upload für Videos

Die Felder müssen aussagekräftige `title` und `description` für die UI besitzen.

## Verhalten
- Das Plugin verwendet `photobooth.plugins.hookimpl`.
- Registriere `photobooth_plugin_config` und `photobooth_plugin_loaded`.
- Verwende `sm_after_transition` oder einen passenden Hook, um nach dem Zustand `completed` hochzuladen.
- Ermittle den Medientyp aus `mediaitem_type`.
- Lade nur hoch, wenn der Medientyp in der Konfiguration erlaubt ist.
- Bestimme den lokalen Pfad zum Medium zuverlässig aus `media_item.processed`, `media_item.captured_original` oder einem Serviceaufruf.
- Verwende die Piwigo-API-Endpunkte:
  - `pwg.session.login`
  - `pwg.images.addSimple`
  - `pwg.images.setInfo`
- Setze `media_item.share_url` nach erfolgreichem Upload.
- Nutze `logger.info` und `logger.error` für relevante Statusmeldungen.

## Fehlerbehandlung
- Behandle fehlgeschlagene API-Aufrufe robust.
- Vermeide Abstürze bei fehlenden Feldern im Media-Item.
- Schreibe aussagekräftige Fehlertexte in die Logs.

## Code-Stil
- Bleibe konsistent mit dem vorhandenen Plugin-Code.
- Verwende `requests.Session()` für API-Aufrufe.
- Verwende `json.loads()` für die Ergebnisverarbeitung.

## Referenzen
- Photobooth Plugin API: https://photobooth-app.org/reference/plugins/
- Photobooth Core Repository: https://github.com/photobooth-app/photobooth-app

## Umsetzungsumfang
- Implementiere die Logik im bestehenden `piwigo.py`.
- Achte darauf, dass bereits vorhandene Konfigurationsfelder erhalten bleiben.
- Optional: Passe `config.example.py` so an, dass die neuen Konfigurationsfelder dokumentiert sind.
